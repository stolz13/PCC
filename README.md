# PCC - Chameleon 🦎☁️

**Chameleon** is an interactive, dynamic JavaScript visualization that generates an evolving, organic 3D cloud-like shape composed of moving points. The visual continually transforms through randomized movement, vibrant color transitions, and user interaction.

---

## 🎨 Overview & Concept

Developed for the **Creative Coding** course (Summer Semester 2024) at **LMU Munich**, *Chameleon* explores the intersection of programming and artistic design. 

The visual experience relies on calculated randomness and continuous state updates. As points drift slowly across the screen, they eventually age out and reset to new positions with updated colors and movement trajectories, ensuring the overall composition constantly evolves.

---

## ✨ Key Features

* **Organic 3D Aesthetics:** Generates a pointed, cloud-like shape with visual depth.
* **Interactive Control:** Allows users to influence the movement, direction, and color of the points in real-time via mouse interaction.
* **Randomized Movement & Color:** Integrates controlled randomness to govern point directions and color changes.
* **Age-Reset Mechanism:** Automatically recycles old points to new coordinates with fresh styles, maintaining an infinitely changing display.
* **Smooth Animation:** High-frequency screen updates create fluid, gradual motion across the display.

---

## 🛠️ Technical Details & Concepts

* **Language:** JavaScript
* **Core Concepts:**
  * Procedural shape generation
  * Random walk & directional vectors
  * Real-time mouse event handling
  * Particle lifecycles (age, reset, and re-initialization)
